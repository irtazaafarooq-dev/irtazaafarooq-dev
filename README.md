## `⚡ Overview`

I build **real websites for real businesses**, from the database to the last scroll animation.

Since **June 2025** I've freelanced as a full-stack developer. I've shipped **two live e-commerce platforms**: a printing business store with its own admin portal, and a **gaming-services marketplace** with logins, online payments, live chat and Discord order alerts. I've also built an **animated portfolio site** for a client.

I care about **interfaces that feel alive** and **back ends that hold up** when real customers use them.
